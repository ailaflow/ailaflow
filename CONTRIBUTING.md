## How to Contribute

1. Fork the repository for the purpose of preparing your Contribution.
2. Create a focused branch for your change.
3. Make your changes.
4. Add or update tests where appropriate.
5. Make sure existing tests and checks pass.
6. Keep the change focused and avoid unrelated refactoring.
7. Open a pull request against the appropriate branch of the official AilaFlow repository.
8. Clearly explain what the Contribution changes and why.
9. Check all required contributor confirmation boxes in the pull request template.

A good pull request should:

- have a clear title and description;
- explain the problem being solved;
- describe any user-visible behavior changes;
- include tests for new or changed behavior where practical;
- update documentation where the Contribution changes documented behavior;
- avoid unrelated formatting or refactoring changes; and
- identify any third-party code, assets, or dependencies introduced by the Contribution.

Submission does not guarantee that a Contribution will be merged.
