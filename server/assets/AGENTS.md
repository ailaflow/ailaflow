## Prompt Language

- Use `MUST` and `MUST NOT` for mandatory behavior.
- Use `SHOULD` and `SHOULD NOT` for defaults that allow justified exceptions.
- Use `MAY` for optional behavior.
- Write requirements as atomic statements with an explicit subject and condition, when applicable.
- Do not use `always`, `never`, or `do not` as substitutes for normative keywords.
- Keep factual descriptions non-normative, and do not strengthen a rule merely for wording consistency.
